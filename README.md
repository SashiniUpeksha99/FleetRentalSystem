# Fleet Rental Management System

## Description
```
This is my Object-Oriented Programming coursework project
The system is used to manage vehicles, customers, and rental agreements in a fleet rental company
```

## Main Features
- User registration and login
- Add and manage vehicles
- Add and manage customers
- Create rental agreements
- Return rented vehicles
- View available vehicles
- Generate simple reports
- Background monitoring using threads

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Composition
- Exception Handling

## Technologies Used
- Java
- IntelliJ IDEA
- Git and GitHub
